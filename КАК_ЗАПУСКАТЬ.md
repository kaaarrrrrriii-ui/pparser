# Как запускать парсер

Команды вводите в приложении «Терминал», находясь в папке проекта. Сначала перейдите в неё:

```bash
cd ~/Documents/pparser
```

## Запуск

1. Откройте приложение **Docker** из папки «Программы» и дождитесь статуса **Engine running**.
2. Запустите проект:

```bash
docker compose up -d
```

3. Откройте в браузере:
   - панель сбора: <http://localhost:8090>
   - CRM с результатами: <http://localhost:8080/#Lead>

Если CRM не открывается сразу, подождите минуту: ей нужно время на старт.

## Как собрать компании

В панели <http://localhost:8090> заполните форму и нажмите **«Собрать и отправить в CRM»**.

| Поле | Яндекс.Карты | 2ГИС |
|---|---|---|
| Город | по-русски: `Москва` | латиницей: `moscow`, `spb`, `kazan` |
| Что искать | `стоматология` | `стоматология` |

Начинайте с небольшого лимита (10–50 компаний) и паузы от 3 секунд. Новые задания выполняются по очереди, поэтому ждать окончания предыдущего не нужно.

То же самое из терминала (запускайте по одному сбору за раз):

```bash
docker compose exec collectors python -m leadgen collect 2gis kazan "стоматология" --limit 10 --delay 3
```

```bash
docker compose exec collectors python -m leadgen collect yandex "Казань" "стоматология" --limit 10 --delay 3
```

## Где смотреть результат

- **Компании, статусы, заметки:** в CRM, <http://localhost:8080/#Lead>.
- **Ход сбора и ошибки:** в панели, раздел «Задания».
- **Сводка в терминале:**

```bash
docker compose exec collectors python -m leadgen status
```

Данные хранятся внутри Docker, а не в папке проекта. Они сохраняются после остановки и перезагрузки Mac.

## Как работать с карточкой в CRM

- **Сменить статус:** откройте компанию и нажмите нужную кнопку вверху карточки: Новый, В работе, Отправить оффер, Cold-email, Успешно, Перезвонить позже или Отказ. Статус сохраняется сразу.
- **Отфильтровать список:** кнопки над списком компаний только показывают компании с выбранным статусом, но ничего не меняют.
- **Указать тип телефона:** нажмите «Редактировать», рядом с номером выберите «Личный» или «Администратор» и сохраните. Парсер тип не знает, поэтому у новых номеров стоит «Не уточнён».

## Перезвоны и напоминания в Telegram

**Назначить перезвон:** откройте лида, в блоке «Перезвоны» выберите дату и время (по Оренбургу), напишите, что сказать, и нажмите **«Назначить перезвон»**. Ниже появится список перезвонов этого лида с кнопкой **«Сделано»**. Все перезвоны видны и в разделе **«Задачи»** слева.

Бот в Telegram:
- присылает напоминание за 10 минут и в момент перезвона: компания, контакт, телефон (нажмите, чтобы позвонить), ваша заметка и ссылка на лида;
- каждый день в 9:30 присылает список перезвонов на сегодня;
- `/today` — перезвоны на сегодня;
- `/remind 12.11 15:30 позвонить клиенту` — быстрое напоминание прямо из Telegram (появится в «Задачах»);
- кнопка **«Сделано»** под напоминанием закрывает задачу в CRM.

Ссылка «Открыть лида в CRM» работает только на этом Mac: CRM доступна лишь с него.

### Первая настройка бота (один раз)

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя и адрес бота (адрес должен заканчиваться на `bot`). BotFather пришлёт **токен** вида `123456789:AA...`. Никому его не пересылайте.
2. Откройте файл настроек:

```bash
open -e ~/Documents/pparser/.env
```

3. Найдите строку `TELEGRAM_BOT_TOKEN=` и вставьте токен сразу после `=`, без пробелов и кавычек. Сохраните файл (⌘S).
4. Перезапустите уведомитель:

```bash
cd ~/Documents/pparser && docker compose up -d notifier
```

5. Найдите своего бота в Telegram и отправьте ему `/start`. Он ответит: «Ваш chat_id: …».
6. Вставьте это число в строку `TELEGRAM_CHAT_ID=` в том же файле `.env`, сохраните и снова выполните команду из шага 4.
7. Отправьте боту `/today` — он должен ответить списком.

Проверить, что бот работает, можно по журналу:

```bash
docker compose logs --tail=30 notifier
```

Строка `Бот @… запущен … chat_id задан` значит, что всё в порядке. Если в журнале ошибки соединения с Telegram, значит, Telegram недоступен из вашей сети: впишите адрес прокси в строку `TELEGRAM_PROXY=` (например `http://user:pass@host:port`) и повторите шаг 4.

Бот отвечает только вашему chat_id, сообщения из других чатов игнорирует.

## Как остановить

Остановить всё, данные останутся:

```bash
docker compose stop
```

Запустить снова:

```bash
docker compose up -d
```

Если выключить только приложение Docker, проект тоже перестанет работать, а данные останутся.

> ⚠️ **Не вводите `docker compose down -v`**: эта команда удаляет все собранные данные, статусы и заметки.

## Частые ошибки

**`Cannot connect to the Docker daemon` или `failed to connect to the docker API`**
Docker не запущен. Откройте его, дождитесь **Engine running** и повторите команду.

**`command not found: docker`**
Закройте окно терминала и откройте новое. Если не помогло, проверьте, что Docker установлен и открывается из папки «Программы».

**В задании написано «Ограничение доступа» или «Яндекс ограничил доступ / запросил CAPTCHA»**
Сайт карт заподозрил автоматический сбор. Это не поломка: найденные компании сохранены, а капчу программа не обходит. Подождите (например, до следующего дня), затем нажмите **«Продолжить»** в строке задания. В следующий раз поставьте лимит поменьше и паузу побольше.

**«Компании не получены»**
Проверьте город и запрос. Частая причина в 2ГИС: город написан по-русски, а нужно латиницей (`kazan`, а не `Казань`).

**Панель или CRM не открываются**
Посмотрите, что запущено:

```bash
docker compose ps
```

Сервисы `collectors`, `espocrm`, `db` и `crm-daemon` должны быть в работе, а `crm-setup` завершается сам, это нормально. Если какого-то нет, запустите `docker compose up -d`. Причину можно посмотреть в журнале:

```bash
docker compose logs --tail=100 collectors
```

```bash
docker compose logs --tail=100 espocrm
```

**`port is already allocated`**
Порт 8080 или 8090 занят другой программой. Закройте её и снова запустите `docker compose up -d`.

**`Run python3 scripts/setup.py`**
Пропал файл `.env` с паролями. Не создавайте новый, если в проекте уже есть данные: сначала поищите старый файл, потому что новые пароли не подойдут к уже созданной базе.

**Компании есть в панели, но не появились в CRM**
Повторите отправку:

```bash
docker compose exec collectors python -m leadgen sync
```

**Всё тормозит**
Сбор и CRM занимают много памяти. Закройте тяжёлые программы и остановите проект, когда он не нужен.

## Проверка, что всё исправно

```bash
.venv/bin/python -m unittest discover -s tests
```

В конце должно появиться `OK`.

## Важно

- Файл `.env` содержит пароли: никому его не отправляйте и не загружайте в интернет.
- Не открывайте панель и CRM для доступа из интернета: входа по паролю в них нет.
- Карты не отдают все компании города, поэтому большой лимит не гарантирует полный список.
- Необязательный ключ `DGIS_API_KEY` добавляет только дату внесения карточки в каталог 2ГИС. Для него допишите в `.env` строку `DGIS_API_KEY=ваш_ключ` и выполните:

```bash
docker compose up -d --build collectors
```
